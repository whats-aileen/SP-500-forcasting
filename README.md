# SP-500-forecasting
a method for forecasting S&amp;P 500 index (by CEEMDAN separation and LSTM learning)
you should generate a series of data which last for 10 years, and this series of data should consist of two columns - date and closing price. 
when you need to forecast the price for the real future, you should use the newest data. I will upload this program when i finished it (i'm still working on it, but i don't have enough time lately)
if you want to read the original paper, search: 
    Forecasting S&P 500 ESG Index by Using CEEMDAN and LSTM approach, Divya Aggarwal and Sougata Banerjee, Journal of Forecasting, 12 September
